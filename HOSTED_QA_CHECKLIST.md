# MS Excel Stimulator — Hosted QA Checklist

Use this checklist after publishing to GitHub Pages, Netlify, or Cloudflare Pages.

## A. Core load
- [ ] Site opens without blank screen
- [ ] Title shows **MS Excel Stimulator**
- [ ] Branding logo and portrait display correctly
- [ ] No obvious broken asset icons are visible

## B. Workbook capacity
- [ ] Workbook supports navigation well beyond row 1000
- [ ] Workbook supports navigation well beyond column Z
- [ ] Scrolling / jumping to distant cells still works

## C. Enterprise features
- [ ] HMG Dashboard opens
- [ ] About the Author opens
- [ ] Workbook Index opens
- [ ] Data Dictionary opens
- [ ] Enterprise Console opens
- [ ] Workbook Search opens and finds matches
- [ ] Audit Log Export downloads
- [ ] Workbook Manifest Export downloads

## D. Premium experience
- [ ] Welcome experience appears in a fresh session
- [ ] Startup choice screen works
- [ ] Animated dashboard counters run
- [ ] Dashboard action cards open the right destination
- [ ] Intro video section appears
- [ ] Presentation Mode toggles correctly

## E. Export and print
- [ ] XLSX export works
- [ ] CSV export works
- [ ] HTML export works
- [ ] Printable author/company report opens
- [ ] PDF-style export workflow opens print dialog
- [ ] Brand Pack export downloads

## F. PWA and offline
- [ ] Manifest loads correctly
- [ ] Service worker registers on hosted HTTPS
- [ ] Browser offers install option or Add to Home screen
- [ ] Reload still works after first load
