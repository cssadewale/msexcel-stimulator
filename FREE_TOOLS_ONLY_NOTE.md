# MS Excel Stimulator — Free Tools Only Note

## Why this matters
This platform is intentionally designed to stay useful without introducing recurring API cost.

## What is used
- HTML
- CSS
- vanilla JavaScript
- browser localStorage
- browser-native downloads
- bundled free SheetJS/XLSX library
- static hosting platforms such as GitHub Pages, Netlify, and Cloudflare Pages

## What is not used
- AI API calls
- paid inference billing
- required backend servers
- paid databases for routine product usage
- subscription-based spreadsheet engines

## Why no AI API is used
AI APIs can become expensive when a browser product grows in traffic or is repeatedly used for interactive features. For this product, core spreadsheet logic, documentation, diagnostics, profiling, and deployment guidance can all be delivered with free browser-side logic instead.

## Practical result
The product stays:
- cheaper to maintain
- easier to host
- easier to hand off
- more predictable in deployment
- more appropriate for static hosting
