## 5. Product Overview

**MS Excel Stimulator** is a **browser-based Microsoft Excel replica** built with **free tools only**.

It runs with:
- HTML
- CSS
- Vanilla JavaScript
- browser localStorage
- a local SheetJS community build for XLSX import/export
- a PWA manifest + service worker for installability

It does **not** use:
- any AI API
- paid inference billing
- a mandatory backend
- a required database server for normal use
- npm build tooling for ordinary end-user operation

This build is now both:
- a functional spreadsheet environment, and
- a branded enterprise-style workbook platform.

## 9. Detailed Feature Explanations

### A. Workbook and sheet management

| Feature | Detailed explanation |
|---|---|
| Multi-sheet workbook | The system supports multiple worksheets inside one workbook, allowing raw data, cleaned data, reports, pivots, dashboards, and branded pages to coexist in one environment. |
| Sheet operations | Users can add, rename, duplicate, move, hide, unhide, and delete sheets, supporting workbook organization similar to spreadsheet office software workflows. |
| Workbook backup / restore | The workbook can be exported as a full JSON snapshot and restored later, providing a free browser-based continuity mechanism without a paid backend. |
| Workbook statistics | The system can summarize workbook-wide counts such as used cells, formulas, comments, charts, and rules. |
| HMG Dashboard | This is the premium branded landing worksheet designed as a workbook entry page, using hero sections, counters, quick actions, and identity blocks. |
| About the Author | This premium worksheet presents the author identity, links, metrics, and brand narrative and is automatically protected to preserve presentation integrity. |
| Workbook Index | This enterprise worksheet summarizes every workbook sheet, listing sheet name, used cells, formulas, comments, chart counts, protection state, and hidden state. It acts as a workbook governance page. |
| Data Dictionary | This enterprise worksheet scans the active source sheet, extracts headers, infers column types, and shows sample values. It helps enterprise users document datasets without external tooling. |

### B. Grid, navigation, and editing

| Feature | Detailed explanation |
|---|---|
| Excel-style grid | The application is structured around a familiar spreadsheet grid with row headers, column headers, and cell-based editing. |
| Large logical grid | The workbook now uses a logical capacity of **2000 rows × 1200 columns**, going far beyond row 1000 and well beyond column Z. |
| Smart render window | Instead of rendering the full logical grid at once, the system renders a sliding visible window around the active area. This is a performance-oriented enhancement for large sheets. |
| Formula bar | The formula bar lets the user inspect and edit raw values and formulas outside the cell area. |
| In-cell editing | Double-clicking or keyboard-triggered edit mode enables direct cell modification. |
| Keyboard navigation | Arrow keys, tab movement, enter movement, and common spreadsheet shortcuts are supported for faster use. |
| Touch support | The app supports tap and double-tap behaviors for tablets and mobile devices. |
| Floating mini toolbar | A contextual formatting toolbar appears during edit workflows for rapid styling access. |
| Live formula highlighting | Referenced cells can be highlighted while formulas are being entered or edited. |

### C. Formula engine and calculation model

| Feature | Detailed explanation |
|---|---|
| Formula evaluation | The engine parses formulas beginning with `=` and evaluates arithmetic, logical, text, date, and lookup expressions. |
| Function coverage | The system includes a wide family of Excel-style functions across math, logic, text, lookup, date, and statistics categories. |
| Named ranges | Users can define human-readable range names and use them in formulas for cleaner model design. |
| Circular reference detection | The evaluator detects circularity and returns an error rather than silently failing. |
| Custom number formats | Users can define display patterns for values beyond the built-in number format set. |

### D. Formatting and presentation

| Feature | Detailed explanation |
|---|---|
| Font and emphasis tools | The system supports font family, size, bold, italic, underline, and strike formatting. |
| Colour tools | Text and cell fill colours help create clearer, more professional workbook layouts. |
| Alignment and wrap | Cell content can be aligned and wrapped for readability and layout control. |
| Borders | Border presets help structure reports, forms, and summary sections. |
| Merge / unmerge | Cells can be merged for title and report designs, then restored as needed. |
| Table styles and cell styles | Built-in styling patterns help users quickly apply more polished workbook formatting. |
| Dark mode | The interface supports dark mode and premium glow effects for improved presentation. |

### E. Data operations and transformation

| Feature | Detailed explanation |
|---|---|
| Sort and multi-sort | Data can be sorted using single-key or multiple-key logic. |
| Filter and regex filter | Users can filter rows using standard conditions or pattern-based matching. |
| Data validation | Validation rules can restrict inputs to defined structures such as lists, numeric ranges, or text/date constraints. |
| Paste Special | Values, formulas, formats, and transformation-style paste behaviors are supported. |
| Text to Columns | Delimited cell content can be split into separate columns. |
| Flash Fill | Example-driven pattern filling is supported for repeated data transformations. |
| Cleanup tools | Trimming, spacing normalization, case conversion, numeric text conversion, and blank-row removal are available. |
| CSV / JSON / XLSX import/export | The workbook supports common file exchange workflows without requiring a server-side processor. |
| Optimized used-range export | Export workflows have been enhanced so they write only the used portion of the workbook rather than blindly exporting every logical row and column. |

### F. Analytics and decision support

| Feature | Detailed explanation |
|---|---|
| Charts | The system can generate chart types for visual analysis directly from selected data. |
| Pivot tables | Pivot generation allows grouped summarization and reporting without external BI tools. |
| Quick Analysis | A rapid action layer lets users apply common totals, charts, or formatting from context. |
| Goal Seek | Users can solve for an input that drives a formula to a target value. |
| Scenarios | Users can preserve named what-if state sets for comparison. |
| Subtotals and consolidate | The workbook supports grouped total insertion and multi-range summary consolidation. |
| Heatmaps, data bars, icon sets, sparklines | These visual layers support enterprise-style data interpretation directly inside cells and ranges. |
| Animated dashboard counters | The HMG Dashboard now animates key stats for stronger brand and presentation impact. |

### G. Review, governance, and enterprise support

## 13. Publisher Checklist (GitHub Pages / Netlify)

### A. Pre-publish checklist
- [ ] Confirm `MS Excel Stimulator/index.html` is the intended release entry point
- [ ] Confirm `MS Excel Stimulator/DataSheet-Pro-v3.html` matches the same build
- [ ] Confirm `MS Excel Stimulator/xlsx.full.min.js` is present
- [ ] Confirm `MS Excel Stimulator/manifest.json` and `MS Excel Stimulator/service-worker.js` are present
- [ ] Confirm all brand assets listed in the file inventory are present
- [ ] Confirm docs are updated: `README.md`, `DEPLOYMENT.md`, `USER_GUIDE.md`, `CHANGELOG.md`
- [ ] Confirm current release number is correct in all docs
- [ ] Confirm dashboard, about page, report, Brand Pack export, Workbook Index, and Data Dictionary all work locally

### B. GitHub Pages-ready repository structure
```text
MS Excel Stimulator/
```

### C. GitHub Pages publishing steps
- [ ] Create or open the target GitHub repository
- [ ] Upload the contents of the `MS Excel Stimulator/` folder to the repository root, preserving the `icons/` folder
- [ ] Commit and push to `main`
- [ ] Open **Settings → Pages**
- [ ] Set source to **Deploy from a branch**
- [ ] Select branch **main** and folder **/ (root)**
- [ ] Save and wait for deployment URL
- [ ] Open the live URL and run the deployment testing matrix

### D. Netlify-ready deployment package
- [ ] Use the `MS Excel Stimulator/` folder directly as the deployment package
- [ ] Open `https://app.netlify.com/drop`
- [ ] Drag the entire `MS Excel Stimulator/` folder into the drop zone
- [ ] Wait for the generated URL
- [ ] Open the site and run the deployment testing matrix
- [ ] If keeping the site permanently, claim the site inside a free Netlify account

### E. Release zip bundle
- [ ] Use the generated `MS-Excel-Stimulator-v5.0.0-release.zip` archive for easy sharing or upload
- [ ] Unzip before GitHub Pages publishing if uploading through the web UI

### F. Final publish walkthrough
1. Open the `MS Excel Stimulator/` folder and confirm all files listed in the package inventory exist.
2. Test `index.html` locally in Chrome or Firefox.
3. Run the deployment testing matrix locally.
4. Publish using GitHub Pages or Netlify.
5. Open the hosted URL and repeat the deployment testing matrix.
6. Hard-refresh once so the latest service worker and assets activate.
7. If needed, document any follow-up patch in `CHANGELOG.md`.
